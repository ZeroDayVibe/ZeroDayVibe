API SECURITY

Thinking about API authorization.

Authorization is about what an authenticated user is allowed to do.

Authentication is not authorization

A valid identity does not automatically mean the user should access every object or action.

Review object-level access

Test whether one authorized account can access another account’s resources within an authorized test environment.

Make controls explicit

Centralize authorization rules where practical and test them at important boundaries.
